# 메모장

접속: https://solocello.github.io/simple-memo/

이메일·비밀번호로 회원가입하면 자동 로그인됩니다. 메모를 입력해 저장하고, 목록에서 삭제할 수 있습니다.

검증 (2026-10-30): GitHub Pages main/(root) 배포 및 실제 첫 화면 접속 확인. API로 테스트 계정 2개를 만들어 가입/자동 로그인, 저장/목록, 세션 갱신, 삭제, 로그아웃/재로그인 및 다른 사용자 메모 조회·삭제·타인 명의 추가 차단을 검증했습니다. 테스트 메모만 삭제했으며 테스트 계정 2개는 남아 있습니다. RLS 및 최소 테이블 권한 확인, Supabase 보안 권고 0건.

남은 검증: 실제 브라우저에서 가입 및 자동 로그인, 저장·새로고침 유지·삭제·로그아웃/재로그인. API 검증은 UI 조작 검증을 대신하지 않습니다.
