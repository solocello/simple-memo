# 메모장

실행: 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save. 배포된 페이지에서 이메일·비밀번호로 회원가입 후 사용합니다.

2026-10-30 확인: Supabase 이메일 자동 확인 활성화, memos 테이블 존재, RLS 활성화 및 SELECT/INSERT/DELETE 소유자 정책 확인. 프런트엔드에는 공개용 키만 사용하며 메모는 textContent로 표시합니다.

미검증: Pages 활성화와 실제 배포 사이트의 첫 접속·가입/자동 로그인·저장/목록·새로고침 유지·삭제·로그아웃/재로그인. 브라우저 GitHub 로그인 후 배포 및 검증 필요.
